# T07 · P1 · 复习调度升级（阶梯拉长 + 出列后复看 + 公共调度器）

> 一句话：把 wrongrev 从 Leitner 一代（[1,2,4,8,16]、出列即终）升级为适配考研 6-12 月尺度的调度器，并抽成公共函数供 T01/T04 复用。

## 背景（为什么）

现状 `WRONG_STEPS = [1,2,4,8,16]`（`src/js/11-insights.js:77`），答对步进、答错归 1、连对 3 次设 `done=true` **永久出列**。三个问题：① 固定步长无难度自适应；② 16 天封顶 + 出列即终——Cepeda 元分析的最优间隔应到周/月级，"已掌握"的题应在 30/90 天有延迟复看（11-insights.js:84 注释自己记录了与题型卡 15 天复看的口径不一致）；③ 调度只管"题"，T01（生词）和 T04（衔接配对）需要同一调度器。

理论依据：间隔效应的最优参数（复习间隔 ≈ 保持期的 10-20%，考研尺度 → 周级起步）；测试效应边界——出列后的延迟复看是防"假掌握"的保险。

## 现状（实码与数据）

- 调度：`wrongSchedule(w, wasCorrect)`（11-insights.js:86-99）、`wrongRevAll()/wrongRevKey()/wrongRevOf()`、`insToday()/insAddDays()` 同文件。
- 侧车键：`wsj_wrongrev`：`{ '<store>|<key>': {n, nextDue, last, done} }`。
- 使用方：错题本重做流（答对/答错调用）、`dueWrongCount()`（07-wordfreq.js:217 引用）。

## 任务（做什么）

1. **抽公共调度器**：把 wrongSchedule 泛化为独立函数（建议仍放 11-insights.js 顶部或新模块，注意 concat 合并顺序）：
   ```js
   // schedule(entry, wasCorrect, quality) → entry
   // entry: {n, nextDue, last, done, lapses}
   ```
   wrongrev / T01 的 vocabrev / T04 的 linkrev 全部走它。阶梯、出列参数作为常量集中定义。
2. **阶梯升级**：`[1,3,7,16,35,90]`。答对步进；答错归 1 并 `lapses+1`。
3. **三档反馈**：重做界面把"答对"拆两档——「答对（犹豫）」/「答对」/「答错」。犹豫档 interval 乘 0.7（不做完整 EF，保留最小自适应口子；UI 三按钮，默认聚焦普通答对）。
4. **出列后延迟复看**：`done=true` 不再是终点——设 `nextDue = insAddDays(30)`；复看答对 → `nextDue = insAddDays(90)` 后深度沉睡（`deep=true`，不再入 due 计数）；复看答错 → 复活归 1 天、`done=false`。
5. **旧数据惰性迁移**：读 wrongrev 时，`done===true && !deep` 且 `last` 距今 >30 天的条目补设 `nextDue=today`（复看一次），`last` 近 30 天内的保持现状等 30 天期满。**不批量重写存储**，读时迁移、写时落盘。
6. **due 计数同步**：`dueWrongCount()` 的口径加注释说明含复看到期项，避免 07-wordfreq.js:216 那类重复计数回归。

## 约束与红线

- 不改 `wsj_wrongrev` 键名与既有字段名（n/nextDue/last/done 保留），只增字段（lapses/deep）——旧备份恢复进来必须直接可用。
- T01 若已先行实施，把它的 schedule 调用点迁移到公共调度器（两处阶梯常量合一）。
- 调度器纯函数化（输入 entry 输出 entry，不直接摸 localStorage），存储读写留在调用方——可测试性。

## 验收（回归断言清单）

- 公共 `schedule` 函数存在，三处调用（wrong/vocab/link 至少 wrong + vocab）走它；
- 阶梯常量 `[1,3,7,16,35,90]`；
- 犹豫档 ×0.7 乘子存在；
- done → 30 天 → 90 天 → deep 的状态机路径完整；
- 惰性迁移逻辑存在且**不批量写盘**（断言：无迁移专用的 setItem 循环）；
- 旧 entry 无 lapses/deep 字段时全部读写路径不抛错（容错断言）；
- 手测：造一条 done 数据把 last 改到 40 天前 → 刷新 → 出现在待复习。
