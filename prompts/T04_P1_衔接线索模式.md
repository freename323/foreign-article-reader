# T04 · P1 · 衔接线索模式（新题型的直接训练）

> 一句话：一键高亮代词/逻辑词/词汇复现链，点选配对"代词→先行词"——新题型（10 分）考的衔接链重建，目前系统零覆盖。

## 背景（为什么）

新题型（7 选 5 / 排序 / 标题匹配）的命题本质是 **Halliday & Hasan 衔接理论**：挖掉的句子前后必然留下衔接残迹——孤立的 this、没有先行词的 they、复现的语义场词。段落功能标签（F02，论点/论据/转折…）练的是修辞结构，**衔接手段完全没练**。同时词汇衔接链（repetition/synonymy/superordinate）也是阅读精读的利器。

理论依据：衔接五类（照应/替代/省略/连接/词汇衔接）；主位推进（Prague school）——段首句是信息生长点。

## 现状（实码与数据）

- 段落功能标签：`bucket='paraFunc'`（`src/js/11-insights.js:385` 起，`src/js/02-content.js:117` 注释了它与文本标注的区分）。
- 视图菜单：`src/js/10-toolbar.js` 的菜单项模式（`menuItemHTML(...)`），词频模式开关 `wsj_reader:freqmode`（07-wordfreq.js:6）是同类先例。
- 正文容器：`.col-body.en p[data-para-idx]`（报纸模式每版都有自己的 col-body，遍历要含全部——07-wordfreq.js:28 有踩坑注释）。

## 任务（做什么）

1. **模式开关**：视图菜单加「🔗 衔接模式」（键 `wsj_reader:linkmode`，三态与词频模式并存但要考虑颜色冲突——进入衔接模式时自动把词频色降为最淡档或关闭，见 T08 的颜色分层）。
2. **代词高亮 + 配对训练**：
   - 自动高亮全部指示/人称代词与限定词：it/they/them/this/these/those/such/one(s)/both/neither/he/she/who/which/whose（清单内置，含句首大写）；
   - **配对是训练不是展示**：点击代词 → 再点击你认为的先行词 → 正确与否给出即时反馈（判定规则 v1：先行词 = 同句或前两句内的名词短语，用简单启发式——前文最近的同数名词/名词短语；判定不确定时只显示候选不强判）；
   - 配对记录进侧车键 `wsj_linkrev`（每篇的配对历史，走 T01/T07 的公共调度：配对全对 → 该篇衔接模式记掌握）。
3. **逻辑连接词四色**：however/nevertheless（转折）、therefore/thus/hence（因果）、moreover/furthermore/in addition（加合）、meanwhile/subsequently（时间）——四类四色下划线，图例常驻。
4. **词汇复现链**：同词族复现（refer/reference/referred；security/insecure——公共词干 ≥4 字母匹配，内置小例外表防误报 family/familiar 类）着同色波浪下划线；不同链不同色（循环 5 色）。
5. **段首句提示**：衔接模式下每段首行加细左侧标线（主位提示，视觉最轻的实现）。

## 约束与红线

- 高亮用 class（`link-pron/link-logic-t/link-chain-1...`）+ CSS，**不新增 span 包装**（正文 DOM 性能红线，参照词频着色的 TreeWalker 但只加 class 不拆节点——注意：Text node 无法挂 class，允许对代词/逻辑词做最小 span 包装，但必须限制在模式开启时、关闭时还原文本节点）。
- 判定逻辑宁缺毋滥：自动判定置信度低时显示候选让人选，错误判定会教错（error persistence）。
- 新键 `wsj_linkrev` 进备份白名单。

## 验收（回归断言清单）

- 模式开关三处完整：菜单项 + localStorage 键 + 渲染入口；
- 代词清单、逻辑词四表、词族匹配函数（含例外表）存在于源码；
- 配对交互代码路径存在（两次点击 → 判定 → 反馈）；
- 模式关闭后正文文本节点还原（无残留 span——DOM 结构断言）；
- 手测：任一文章开启 → 代词着色 → 完成一次配对 → 关闭 → 正文干净。
