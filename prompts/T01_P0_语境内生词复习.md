# T01 · P0 · 语境内生词复习（遮盖式重读 + 段落填空）

> 一句话：给已经标注的生词装上"费力取出"的出口——到期词回**原段落**遮盖重读 / 挖空填词，复习单位是段落，不是卡片。
> 这是整个改进计划的地基任务（T03/T07 依赖它的调度键）。

## 背景（为什么）

生词标注（bucket=vocab）目前的全部后续只有两个：词频着色里标金色（`src/js/07-wordfreq.js:38` 的 freq-v，被动视觉提示）、CSV 导出 Anki（外包给外部闪卡工具）。`dueReviewCount()`（07-wordfreq.js:198）只数题型标注（qtype）和错题——**生词零调度、零检索**。按加工水平理论与测试效应：划词是浅加工（有 noticing，无 retrieval），天天制造 storage，考场要用的 retrieval 恒为零。

理论依据：编码特异性原则（Tulving & Thomson）——提取成功率最高的语境是编码语境。把复习放回原段落，迁移率**高于**孤立闪卡（这也正是本项目闪卡红线的科学理由）。

## 现状（实码与数据）

- 生词数据：`annotations:<articleId>`（key 见 `src/js/00-head.js:30`）里 `bucket === 'vocab'` 的条目，**已有字段** `text`（词）、`context`（上下文）、`paraIdx`（段落号）、`source`（en/cn）、`createdAt`——复习所需的定位数据全齐。
- 词频金色：`applyFreqColoring()`（07-wordfreq.js）里 vocabSet 把已标注词标 freq-v。
- 默写错词：`wsj_dictation:wrongs`（`src/js/12-dictation.js`）可"并进生词本"——并入后目前只是变金色标注，同样掉进黑洞。
- 调度参照物：`wsj_wrongrev` 侧车（`src/js/11-insights.js:75-100`），`{ '<store>|<key>': {n, nextDue, last, done} }`，`insToday()/insAddDays()` 工具在 11-insights.js。
- 词比对容错参照：`12-dictation.js` 的 `dictWords()`（提取词 token）与逐词比对逻辑（大小写/屈折处理）。

## 任务（做什么）

1. **新键 `wsj_vocabrev`**（侧车，格式同 wrongrev）：`{ '<articleId>|<lowercased text>': { n, nextDue, last, done, strength } }`。加入 `09-reading.js` 的 `BACKUP_EXACT_KEYS`。首次出现即登记（标注生词时惰性登记，或复习入口首次扫描时登记，选后者更省写入）。
2. **复习入口**：工具栏「数据」菜单或精读分析台加「🎯 今日生词复习」→ 扫描全部 `annotations:*` 的 vocab 条目，按 `nextDue <= today` 过滤，**按文章聚合成复习单**（每篇列出：文章名、到期词数、「开始重读」按钮）。
3. **遮盖式重读**：点开文章 → 段内到期词渲染为涂黑块（`span.vrev-mask`），点击/悬停显形（保留原高亮逻辑 underneath）。该篇所有到期词都点开过 = 完成一轮，逐词记调度（点开即"想起来了"算答对；提供「没想起来」长按/右键选项算答错）。
4. **段落填空模式**：同段 ≥3 个到期词时可选"填空模式"——这些词挖成输入框，逐词键入判定（复用 dictWords 的容错），判对/判错直接写调度。
5. **词级默写（无语境回退形态）**：通过 T03 收件箱入池的词没有原文段落——复习形态退化为"看中文释义键入英文词"。此形态在本任务一并实现（数据源 `wsj_vocabrev` 条目带 `gloss` 字段存释义，可空）。
6. **渐退提示**：freq-v 金色的透明度按 `strength`（连续答对次数）递减——0 次答对 = 实心金，之后逐级变浅，答对 3 次后不再着色（但标注仍在）。这是颜色获得时间维度。
7. **调度规则**：答对步进、答错归 1 天，阶梯先用 `[1,2,4,8,16,35]`（T07 会升级为公共调度器，接口留好：`schedule(entry, wasCorrect)` 独立函数）。

## 约束与红线

- 闪卡红线：涂黑块在**原段落里**，不是弹出卡片。禁止独立的卡片翻转 UI。
- 涂黑块用 class 控制，不新增 span 包装层（性能，见全局约束）。
- 不改 annotations 的既有字段结构，只加侧车键。

## 验收（回归断言清单，写入 `_v{N}_regression.js`）

- `wsj_vocabrev` 键定义存在且在 `BACKUP_EXACT_KEYS`；
- 遮盖类名 `vrev-mask` 存在于 CSS 与渲染代码；
- 调度函数 `schedule` 存在、阶梯常量为 `[1,2,4,8,16,35]`；
- 填空模式逐词判定调用 dictWords 同源逻辑（或同规则副本）；
- 渐退提示：freq-v 透明度与 strength 联动的 CSS 变量/类存在；
- 手测路径：标 3 个词 → 复习入口出现 → 遮盖重读一轮 → wrongrev 式记录写入。
