# T03 · P0 · 词汇收件箱（外部词表回流）

> 一句话：一个粘贴框把任何来源的词表（单词积累.md、手机上查的词）收进系统、入复习调度——让"全部英语学习回归阅读器"这句话有实际的管道。

**依赖**：T01 的 `wsj_vocabrev` 调度键与其词级默写形态。先做 T01。

## 背景（为什么）

用户的定位是：考研全程的英语学习（阅读器内文章深耕 + 一切外部学习）都回流到这个系统。现状是三条回流管道全是"一次性脚本 + 手工搬运"（文库扫描只认自家版式、模板导入 JSON、作文包转换器）。最大的外部词汇资产——`英语作文包_20260930/英语作文包_20260930/2_单词积累/外刊单词积累.md`（56 个日期分区、900+ 词，含词性/英译/中译四列表格）——完全在系统外。

理论依据：中枢系统的"瓣膜"问题——单向回流等于没有回流。附带习得（Webb：10+ 次相遇才产出性掌握）要求外部词必须进入**有调度**的重遇循环，而不是躺着当金色高亮。

## 现状（实码与数据）

- 单词积累.md 的分区格式（粘贴目标格式）：
  ```
  2026/05/05

  **来源**：B站·秋刀鱼（诺曼征服与英语词汇阶级分化）
  **类型**：外刊阅读

  | 单词 | 词性 | 英文释义 | 中文释义 |
  |-----|------|---------|---------|
  | swine | n. | a pig (old-fashioned...) | 猪（古英语...） |
  ```
  也有纯词列、`word - 释义` 行等其他来源格式。
- 调度池：T01 建立的 `wsj_vocabrev`（含 `gloss` 字段存释义）。
- 去重比对源：全部 `annotations:*` 的 vocab 条目 + `wsj_vocabrev` 既有条目。

## 任务（做什么）

1. **收件箱面板**：文库（WSJ_Hub）工具区加「📥 词汇收件箱」入口，独立面板：
   - 粘贴框（多行文本）+ 来源标签输入（如「单词积累 2026/05/05」「手机生词」）；
   - 「解析预览」：自动识别三种格式——① markdown 表格（取"单词"列 + 释义列）② 每行一词 ③ `word | 释义` / `word - 释义` / `word：释义` 分隔行；
   - 预览列表逐行可勾选，重复词（与比对源命中，忽略大小写）默认不勾并标「已存在」。
2. **入池**：勾选项写入 `wsj_vocabrev`（`nextDue = today`，`gloss = 释义`，`src = 来源标签`），无原文挂靠 → 走 T01 的词级默写形态复习；有朝一日该词在文章里被标注，合并到标注条目（同 articleId 挂靠）。
3. **收件箱历史**：`wsj_inbox:log` 记每次导入（日期/来源/条数），面板底部展示——中枢的回流账本。
4. （可选 v2）文件读取：支持直接选 `.md` 文件（FileReader，参照工坊模板导入的 `#tpl-file` 实现模式）。

## 约束与红线

- 闪卡红线：入池不是建卡——复习走 T01 的词级默写/段落填空，永不弹卡片。
- 新键 `wsj_vocabrev`（T01 已建）+ `wsj_inbox:log` 都进 `BACKUP_EXACT_KEYS`。
- 解析器对脏数据宽容（半行、空行、表格断列不炸），解析失败行标红跳过不阻塞整批。

## 验收（回归断言清单）

- 三种格式的解析正则存在且互不误伤（单元断言：给定样例文本，解析出正确词/释义对）；
- 去重逻辑：与 annotations vocab + vocabrev 比对（lowercase）；
- 入池后 `dueReviewCount` 或 T01 的生词复习入口计数上升；
- `wsj_inbox:log` 写入且在备份白名单；
- 手测：粘贴单词积累.md 一个分区 → 预览 → 入池 → T01 复习入口出现这批词（词级默写形态）。
