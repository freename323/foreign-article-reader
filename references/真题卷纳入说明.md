# 真题卷纳入说明（考研英语一）

> 真题 PDF 放在项目根目录的 **`papers/`** 文件夹（该目录已在 `.gitignore` 中，
> 不会进入公开仓库——真题属版权内容，与 `articles/` 同一待遇）。

## 〇、真题卷直接模考（主路径，无需任何转化）

**入口：任意文章页 → 🎓 考试 → 📄 真题卷模考（2010-2026）**，或直接打开 `articles/paper_exam.html`。

- 左侧**内嵌真题 PDF 原卷**（`../papers/<year>-yingyi.pdf`），右侧是标准答题卡：
  - Section I 完形填空 1–20（A–D，每题 0.5 分）
  - Section II Part A 阅读理解 21–40（A–D，每题 2 分）
  - Section II Part B 新题型 41–45（A–G，每题 2 分）
  - Part C 翻译 + Section III 写作：主观题自评（对照解析的参考译文/范文）
- 180 分钟倒计时（绝对时间戳，刷新不走时，超时自动交卷）；不开计时也可自由训练
- 答题卡点选即存本机（`wsj_paper:<year>`），再点一次取消
- **答案键**：解析下载好后，把客观题答案粘进 🔑 答案键（支持 `1.B 2.D` 与 `1-5 BDCAB` 两种格式混排），
  交卷即自动判分并计入本卷历史（`wsj_paper:history`）
- 每年的作答 / 答案键 / 历史互相独立，切换年份互不影响

## 一、放什么、怎么命名

```
papers/
  2010-yingyi.pdf ... 2026-yingyi.pdf   # 当前已就位 17 年
  txt/2010.txt ...                       # pdftotext 提取的全文（供检索/后续转化用）
  manifest.json                          # 结构档案（scripts/_papers_manifest.py 生成）
```

命名约定 `年份-yingyi.pdf`（paper_exam.html 按此寻址）。

## 二、（可选路径）转成题库模块页

若某一年想要「逐题解析 + 错题字典 + 与外刊混组卷」的深度练习体验，可以**额外**把它转成
题库页（exam_<year>.html 等）——流程走《新增文章纳入流程》：

1. **阅读 Part A**：按 `scripts/_PROMPT_TEMPLATE.md` 的题库规范抽出 4-5 道题 +
   逐题解析（5 层结构），生成 `exam_<year>yingyi.html`；
2. **完形 / 新题型 / 翻译**：分别按 cloze / newtype / translation 模块的数据格式生成对应页面；
3. 转出的 slug 出现在「整卷模考」（exam_full.html）篇目下拉（运行期自动登记），
   即可与外刊题库混合组卷。

> 现状（见 manifest.json）：16/17 年结构可解析；2024 年 PDF 文本层损坏（需换源）；
> 答案键 0/17 随卷——走转化路径前需先补一份「答案及解析」合集。

## 三、转化路径与直接模考的关系

| | 直接模考（paper_exam.html） | 转题库（exam_*.html 等） |
|---|---|---|
| 内容形态 | PDF 原卷（保真版面） | 结构化题目 + 逐题解析 |
| 计时判分 | 整卷 180 分钟 + 答题卡 + 答案键 | 每模块独立计时判分 |
| 错题字典 / 间隔复习 | 无 | 有（接入错题本与雷达） |
| 与外刊混组卷 | 否（卷就是卷） | 是（exam_full 按位组卷） |

两条路径并存：平时**直接模考**用真题保持手感；想精研某一年的错题时再考虑是否值得转题库。
