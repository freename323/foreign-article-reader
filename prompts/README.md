## 全局约束（每个任务都必须遵守，不再在各文件重复）

1. **闪卡红线（最高优先）**：任何复习/记忆 UI 不得做成翻卡或 Anki 式卡片。复习单位是**段落、文章、题**，不是卡片。
2. **localStorage 规约**：新建键一律 `wsj_` 前缀；**必须**同时加进 `src/js/09-reading.js` 的 `BACKUP_EXACT_KEYS`（约 179 行），否则备份静默漏数据。参照 `wsj_wrongrev` 的侧车模式（`{n, nextDue, last, done}`）。
3. **构建链**：改 `src/js/*.js` 后必须执行：
   ```
   python scripts/concat_reader.py && node --check src/reader.js
   ```
   然后拷贝产物：`src/reader.js → articles/reader.js`、`src/reader.css → articles/reader.css`、`src/js/06-exam.js → articles/exam-panel.js`（懒加载独立产物，**漏拷 = 改了没生效**）。新增 src 模块前先读 `scripts/concat_reader.py` 弄清合并顺序（注意 10-toolbar.js 负责收尾 IIFE，各模块有排序约束）。
4. **回归测试**：每个任务新建 `articles/_v{N}_regression.js`（模式参照 `_v35/_v36/_v37/_v39`：读源码做静态断言 + 产物同步比对）。**版本号开工时取 `articles/_v*_regression.js` 当前最大号 +1**（2026-09-30 时为 v39，下一个 v40）。提交前跑**全套**既有回归 + 新回归，全绿才提交。

6. **主题色值**：文章页 `src/reader.css` 是唯一基准（v37 已对齐）；文库模板 `scripts/WSJ_Hub_template.html` 同步改，改完拷 `articles/WSJ_Hub.html`。
