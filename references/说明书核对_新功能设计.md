## 〇、说明书里必须先纠正的三处

### 1）`articleMeta.id` 不存在，且「不用文件名」这条是反的

说明书「五、通用兼容性约束 1」写：*使用 `articleMeta.id` 作为文章标识，不使用 URL 文件名*。

事实：`articleMeta` 只有 `id`（= 页面文件名）/ `slug`（= 栏目 ID）。全项目的 localStorage 主键
（`annotations:` / `summary:` / `translation:` / `syntax:` / `reading:` / `settings:`）**后缀都是文件名**，
Hub / 对比阅读 / 文件系统扫描 / `navigateToRef` 也都把 id 当文件名用。
照说明书改会把所有存量数据读不到（这是上一份规范里已经踩过一次的坑）。

说明书自己的示例 `"articleId": "ai_cost"` 也印证了这一点 —— 那是 **slug**，不是文章标识。

### 2）新 key 命名与现有 4 套错题库并存 = 数据分裂

说明书要新建 `exam:wrong:<articleId>`，但项目里已经有 **4 个错题库**：

| 现有键 | 谁写 | 形状 |
|---|---|---|
| `wsj_exam:wrongs` | `exam.js`（阅读理解） | `{key, slug, title, no, type, myAnswer, answer, cause, stem?, options?}` |
| `wsj_cloze:wrongs` | `cloze.js` | `{key, slug, mode:'cloze', kind, no, myAnswer, answer, cause}` |
| `wsj_newtype:wrongs` | `newtype.js` | 同上结构 |
| `wsj_translation:wrongs` | `translation.js` | `{key, slug, mode:'translation', no, score, myAnswer, ref, cause}` |

同时 `wsj_exam:history`（4 个模块共写）里 **逐题存了 `perQ[].type` 与 `cause`**。
再建一套新键，等于同一件事有 5 份真相。

同理：`writing:materials` / `writing:synonyms` → 现有是 `wsj_writing:materials` / `wsj_writing:advice`；
`exam:stats:<articleId>` → 现有 `wsj_exam:history` 已经够用；`vocab:index` → 不必要（见 F07）。

### 3）漏了一条「新增浮层必须抬层级」的硬约束

`.paper-root` 是 `z-index:9000` 的**不透明**整屏元素。挂在 `body` 下、层级低于它的浮层
在默认的报纸阅读模式下**全被盖住**（详见文末「本次修掉的 P0」）。

## 三、本次修掉的 P0：报纸模式下所有浮层被纸面盖住

**症状**：默认的报纸阅读模式下，**选中文字后的批注菜单不出现**（生词 / 笔记 / 长难句 / 素材 / 词根
全都从这个菜单进），长难句 / 素材 / 写作工坊 / 阅读统计 / 文章关联面板、备份对话框也都不出现。
表现是「点了没反应」，不报错。

**根因**：`.paper-root` 是 `position:fixed; inset:0; z-index:9000` 且纸面不透明；而上述浮层都挂在
`body` 下、是它的**兄弟节点**，原层级全部低于 9000：

| 浮层 | 原层级 |
|---|---|
| `.crossref-panel` | 50 |
| `.bookmark-pill` | 95 |
| `.progress-bar` | 100 |
| `.float-menu` / `.backref-banner` | 200 |
| `.syntax-panel` / `.backup-overlay` | 300 |
| `.paper-root` | **9000** |
| `.summary-col` / `.notes-section` | 9200（这两处当初特意抬过） |
| `.exam-hub` | 9500 |

**修法**：在 `reader.css` 末尾统一抬层级 —— 交互菜单类 → 9250，面板类 → 9300，
并保持彼此原有的相对顺序。**新增任何挂在 body 下的浮层都要在那一块补一条**。
