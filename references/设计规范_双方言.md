# 设计规范 · 双方言视觉体系（T10）

> 来源：九维剖析第十层。仓库并存两套设计语言，历史上三次风格冲突（文库主题 v37、作文索引重做、报头叠压 v38）都源于**边界不明确**，而非某套语言本身有问题。本文档定义边界、共享层与领地协议；新页面/新面板开工前先过第四节的检查单。

---

## 一、两种方言的定义

| | **A · 纸质印刷语言** | **B · Web 应用语言** |
|---|---|---|
| 气质 | 书页、报纸、电子书 | 工具、面板、仪表盘 |
| 字体 | 衬线栈：`Georgia, "Noto Serif SC", "Source Han Serif SC", SimSun, serif`（报纸用 `--np-serif/--np-cond/--np-mono` 变体） | 无衬线栈：`-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif` |
| 底色 | 纸面：`--np-paper`（#fbfcfd / #141920 暗报）/ 主题 `--bg`（#fafaf7 等） | 卡片 `--card-bg` + 强调色按钮 |
| 形状 | 直角或小圆角（≤2px）、双细线（`double`）、点线下划线 | 6–10px 圆角卡片、实色按钮、阴影浮层 |
| 色彩策略 | 墨色（--np-ink）为主，强调色极少 | 主题 accent 大面积使用 |
| 代表实现 | 报纸模式（10-newspaper.js）、调色版范文、作文文库索引（v46 后） | 文库（WSJ_Hub）、练习页、写作工坊、精读分析台、独立写作页 |

## 二、适用边界判定规则（三条，按序命中即停）

1. **内容是"要被长期阅读的成文"**（文章正文、范文、默写原句）→ A。
2. **内容是"操作/管理/数据"**（列表管理、练习作答、统计面板、导入导出）→ B。
3. **混合体**（如剪报本：既有阅读又有按钮）→ 容器用 B 的交互骨架 + 内容区用 A 的阅读排版（报纸模式下的剪报本抽屉即此形态）。

**推论**：同一功能在两种阅读形态下允许换方言——三栏视图的笔记面板是 B；报纸模式的剪报本抽屉是「B 骨架 + A 内容」。

## 三、共享层规范（两套方言都从这里取值）

### 3.1 色板
- **唯一基准：`src/reader.css` 四主题**（light/dark/green/blue-gold）。v37 起文库模板色值与之逐项对齐；任何新页面禁止自拟主题色（违规案例：作文文库索引 v1 的绿底、报头工具条 v1）。
- 报纸专用变量（--np-ink/--np-paper/--np-rule/--np-accent）只存在于 `body.paper-open` 作用域，出了报纸模式不得引用。
- 强调色语义：`--accent`（交互主色）、`--accent-bg`（交互底）、`--cn-tag/--en-tag`（语言标签）、freq-v 金（生词，v40 起带渐退透明度）。

### 3.2 字体
- 阅读正文一律衬线栈；按钮/表单/标签一律无衬线栈。**禁止**在按钮上用衬线（当前合规）。

### 3.3 层叠（z-index 领地协议，实测自 reader.css）
| 层 | z | 成员 |
|---|---|---|
| 页面流 | 1–100 | progress(100)、menu-dropdown(60)、bookmark(95)、crossref(50)、mobile-bar(90) |
| 浮动工具 | 200 | float-menu(200)、backref-banner(200)、hub 内浮层(200) |
| 重叠面板 | 300 | backup-overlay(300)、居中大面板(300) |
| 报纸根 | 9000 | paper-root(9000) —— 报纸模式的"地面"，其内元素相对它排 |
| 报纸抽屉 | 9200 | paper-open 的 summary-col / notes-section（剪报本） |
| 报纸浮层 | 9250–9300 | paper-open 的 bookmark(9250)、stats/exam 工坊面板(9300) |
| 考试总览 | 9500 | exam-hub |
| 全屏遮罩 | 9998/9999 | 历史面板(9998)、(9999) 全屏 |

**规则**：新浮层的 z 值必须落在上表现有档位内；报纸模式内的浮层一律 9250/9300，不得另立（v38 的剪报本折叠钮因此返工过）。hub 内自建浮层（v41 收件箱 z=200）遵循 hub 本地档位。

### 3.4 按钮两式
- A 式（印刷）：透明底 + 1px `--np-rule/--np-ink` 边框 + 无衬线 11.5–13px，悬停反白。
- B 式（应用）：`.primary`（accent 实色）/ `.ghost`（边框）+ 圆角 6–8px。
- 两式不得混用在同一按钮上（曾有 `style` 内联色覆盖主题的个案——以类名为准）。

## 四、新页面/新面板选型检查单

1. 这个界面 80% 的面积是「读成文」还是「操作」？（读 → A；操作 → B）
2. 它出现在哪种阅读形态里？宿主是 A（报纸）则内容区随 A。
3. 它的颜色是否全部来自共享色板（第二节）？——出现硬编码 hex 即违规（调色版范文等**外部成稿**除外，它们自带完整设计）。

## 五、清点清单（2026-09-30 走查）

| 页面/场景 | 方言 | 结论 |
|---|---|---|
| 文章页三栏视图 | B（工具）+ A（正文衬线） | ✅ 合规（正文本就是 A 的阅读排版） |
| 报纸模式（np-*） | A | ✅ 规范范本 |
| 剪报本（三栏折叠条） | B | ✅ |
| 剪报本（报纸抽屉/右下钮 v38） | B 骨架 + A 内容 | ✅ |
| 写作工坊面板（12 页签） | B | ✅（长难句原文区已是衬线，符合混合体规则 3） |
| 独立写作页 | B 骨架 + A 正文 | ✅ |
| 文库（WSJ_Hub） | B | ✅ v37 起色值对齐 |
| 作文库索引（essays/index.html） | A | ✅ v46 对齐调色版 |
| 调色版范文 HTML | A（自带） | ✅ 外部成稿，不参与共享色板 |
| 四类练习页（exam/cloze/newtype/translation） | B | ✅ |
| 模拟套卷 exam_paper.html | B | ✅ 墨色顶条呼应报纸，边界内 |
| 精读分析台各面板 | B | ✅ |
| 浮动菜单（选词工具条） | B | ✅ |

**越界结论**：当前无必须立即修复的越界；唯一 ⚠ 项（收件箱内联样式）为低优先级技术债，已在行内注释自证来源（v41），可随 hub 下一次改版收敛。
