英语学习软件编码逻辑调研报告

调研对象：Duolingo · Grammarly · MarginNote · 扇贝考研 ｜ 产品场景：10篇外刊 + 阅读模式 + 考研英语一考试模式 ｜ 2026-09-24

产品定位与核心约束

本报告所有建议均基于以下产品事实：

  • 内容载体：10篇精选外刊文章（WSJ / Science / SundayTimes），每篇是独立的学习单元
  • 双模式：阅读模式（精读、标注、笔记）+ 考试模式（仿照考研英语一）
  • 考试对标：考研英语一 = 完形10分 + 阅读A 40分 + 新题型10分 + 翻译10分 + 小作文10分 + 大作文20分
  • 技术约束：纯前端 HTML/JS，localStorage 存储，无后端，单文件可部署
  • 核心目标：通过10篇文章的深度精读 + 考试练习，实现考研英语能力的实质性提升

一、四款产品编码逻辑速览

1.1 Duolingo — 练习驱动 + Server-Driven UI

MVVMRepositorySDUI间隔重复

  • SDUI 架构：后端返回 SDUIResponse（screens + components + stylesheet + dataModel），客户端只负责渲染，新增练习类型只需后端加配置
  • 练习数据驱动：每种练习是 JSON（type/prompt/options/solution），前端按 type 渲染对应交互组件
  • 间隔重复引擎：根据记忆衰减曲线调度复习内容，不是按时间倒序展示
  • 游戏化状态：XP / Streak / Hearts / Leagues 都是独立数据结构，与练习内容解耦

1.2 Grammarly — 实时文本分析 + OT协同编辑

QuillJSDelta格式OT协议GECToR

  • Delta 变更记录：文本变更只用 insert/delete/retain 三种原子操作，比存全文省空间，天然支持版本历史
  • OT 协同：变更队列 + rebase 模块，乐观更新UI，服务器ACK后确认，类似Git rebase
  • 下划线渲染：不修改原文本，只包装文本节点加 underline 样式，点击弹出建议卡片 accept/dismiss
  • 双层模型：端上快速模型（纠错/预测）+ 后端深度模型（句子级分析）

1.3 MarginNote — 精读笔记 + FSRS间隔重复

卡片溯源双向链接FSRS语境复习

  • 卡片始终绑定来源：书 → 章节 → 脑图节点 → 原文段落，复习时一键回原文
  • FSRS 算法：比传统SM-2省30%复习时间，每张卡个性化计算下次复习时间
  • 语境复习：复习时显示原文整段而非孤立例句，记忆强度完全不同
  • 四向复习：EN→CN、CN→EN、听音识义、看例默词
  • 双向链接：卡片间 wiki 式 [[标题]] 关联，跨文章串联同一概念

1.4 扇贝考研 — 考研垂直 + AI批改

真题驱动AI作文批改模板查重三维评分

  • 作文批改：AI大模型 + 考研评分标准匹配系统，从逻辑结构/句式优化/用词适配性三维打分
  • 模板查重：识别热门模板句，在原文中标注，提醒用户改写避免撞车
  • 真题词汇：考纲单词与真题语境绑定，阅读中遇到的词自动入词本
  • 错题追踪：按题型/知识点分类错题，生成薄弱点诊断

二、考研英语一题型与10篇文章的能力映射

考研英语一的每种题型都对应特定能力，而10篇外刊文章是这些能力的共同载体。关键在于：阅读模式积累的素材，必须能直接服务于考试模式的练习。

题型分值核心能力10篇文章可提供的素材当前产品覆盖
完形填空10分词汇辨析 + 上下文逻辑文章中的近义词组、逻辑连接词部分 有生词本，无完形练习
阅读A40分细节定位 + 推理判断 + 主旨概括文章本身 + 题目有 考试模式有阅读题
新题型10分段落逻辑 + 语篇衔接文章段落结构有 七选五/排序/小标题
翻译10分长难句拆解 + 英译汉文章中的长难句有 翻译练习 + 长难句面板
小作文10分应用文格式 + 套话积累文章中的正式表达弱 写作工坊有素材，无应用文模板
大作文20分图画描述 + 逻辑论证 + 高级表达文章中的论点/论据/高级句式弱 有建议文积累，无大作文框架
核心缺口：写作部分（30分占比最高）的产品支撑最弱；完形填空完全缺失；阅读积累与考试练习之间没有数据打通。

三、外刊精读方法论的产品化路径

3.1 新东方/奇速英语推荐的精读三步法

  1. 结构解码（20分钟）：拆解标题隐含信息，标注每段功能（论点/论据/转折/结论），绘制逻辑结构图
  2. 语言攻坚（20分钟）：筛选高频词汇，整理同义词替换表，拆解长难句主干，进行仿写练习
  3. 对照修正：对照译文排查理解偏差，重点梳理中英文表达差异

3.2 当前产品的覆盖与缺口

精读步骤方法论要求当前功能缺口
结构解码段落功能标注 + 逻辑结构图段落概要 + 翻译无段落功能标签（论点/论据/转折），无逻辑结构图
语言攻坚-词汇高频词筛选 + 同义词替换表生词本 + 词频着色无同义词替换表，无跨文章词汇关联
语言攻坚-长难句主干拆解 + 仿写长难句面板（存句子+笔记）无主干标注工具，无仿写练习入口
对照修正译文对照 + 偏差记录中英三栏对照无"理解偏差"标注功能

四、考研错题复盘的产品化路径

4.1 考研阅读错题的三层复盘法

  1. 第一层：知道对错（大多数人停在这层）
  2. 第二层：为什么错——词汇不认识？定位错误？逻辑没搞清？干扰项陷阱？
  3. 第三层：同类题规律——错误选项的四大陷阱：偷换概念 / 过度推理 / 无中生有 / 正反混淆

4.2 错题数据结构建议

{
  "id": "q_001",
  "articleId": "ai_cost",
  "questionType": "detail",        // detail/inference/main_idea/vocabulary
  "userAnswer": "B",
  "correctAnswer": "C",
  "wrongReason": "logic",          // vocab/location/logic/trap
  "trapType": "over_infer",        // steal_concept/over_infer/not_exist/reverse
  "note": "原文说may，选项改成will，过度推理",
  "reviewCount": 0,
  "lastReview": null,
  "mastered": false
}
当前考试模式只有对错统计，没有错题归因和陷阱类型标签。这是从"刷题机器"到"考点预判者"的关键跨越。

五、对外刊阅读器的深度改进建议（重点）

5.1 阅读模式：从"能读"到"精读"

P0 段落功能标签系统

借鉴：精读方法论中的"结构解码" + MarginNote 的来源绑定

实现：每段加一个可点击的功能标签按钮，用户标注该段是 论点 / 论据 / 转折 / 结论 / 背景 / 例证。标签存在 annotations:<articleId> 的新 bucket 中。

价值：

  • 新题型（七选五/排序）本质考的就是段落功能判断，提前训练
  • 阅读A的主旨题/推理题需要快速定位论点段，标签可加速定位
  • 10篇文章都标注后，可以跨文章对比"论点-论据"结构模式

P0 已积累内容在原文中的可视化标注

借鉴：Grammarly 下划线渲染（包装文本节点，不修改原文）

实现：用户存过的生词、长难句、写作素材，在原文中用不同颜色下划线标注：

颜色含义点击行为
红色波浪生词弹出释义 + 已存笔记
蓝色下划线长难句弹出长难句分析 + 结构笔记
绿色高亮写作素材弹出素材卡片（起因/经过/逻辑）
紫色虚线理解偏差弹出当时的错误理解 vs 正确译文

技术要点：用 Range API 包装文本节点，和 Grammarly 一样不修改原文 HTML，滚动时自动跟随。

P1 同义词替换表

借鉴：精读方法论中的"语言攻坚" + 考研写作的高级表达替换

实现：用户选中一个词（如 important），可以添加"高级替换"（crucial / vital / significant / indispensable），存在 wsj_writing:synonyms 中。写作时可以查阅。

扩展：10篇文章中出现的同义表达自动聚类（如 show / demonstrate / illustrate / reveal），形成文章级替换表。

P1 长难句主干标注工具

借鉴：奇速英语"长难句解析标主干" + 翻译题型要求

实现：长难句面板中增加"标主干"模式——用户点击句子中的主谓宾，系统用颜色区分：

  • 主语 = 蓝色，谓语 = 红色，宾语 = 绿色
  • 定语从句 = 黄色背景，状语从句 = 紫色背景，非谓语 = 灰色删除线

价值：翻译题（10分）的核心就是长难句拆解，这是直接的应试训练。

P2 理解偏差标注

用户对照译文发现自己理解错了某句，可以选中原句标注"理解偏差"，记录自己的错误理解。复习时优先看这些句子。

5.2 考试模式：从"做题"到"复盘"

P0 错题归因系统

借鉴：考研错题三层复盘法 + 扇贝考研的薄弱点诊断

实现：每道错题提交后，弹出归因选择：

错误原因说明对应训练
vocab 词汇不认识关键词/选项词不认识自动加入生词本，标记"考试错词"
location 定位错误没找到出题句高亮出题句，训练定位技巧
logic 逻辑没搞清句子/段落逻辑理解错关联长难句分析
trap 干扰项陷阱被错误选项迷惑选择陷阱类型：偷换概念/过度推理/无中生有/正反混淆

数据存储：exam:wrong:<articleId>，每题含 wrongReason + trapType + note。

P0 错题本 + 间隔重复复习

借鉴：MarginNote FSRS + Duolingo 间隔重复

实现：

  • 所有错题自动进入"错题本"，按题型和错误原因分类
  • 用简化版间隔重复（不必完整FSRS，用1天/3天/7天/14天梯度）调度复习
  • 复习时显示原题 + 文章出处 + 当时的错误原因，遮答案重做
  • 连续答对2次标记"已掌握"，移出复习队列

工具栏显示：当前"复习生词（文库）"旁边加"复习错题（N道）"。

P1 完形填空练习生成

借鉴：考研完形题型 + Duolingo 自动出题

实现：从10篇文章中自动挖空生成完形练习：

  • 选择文章中的实词（动词/名词/形容词/副词）作为空
  • 每空提供4个选项（正确答案 + 3个干扰项，干扰项从同词性词汇中选）
  • 20空一篇，计时15分钟，仿真实考试
  • 做完后显示每空的上下文逻辑分析

技术要点：挖空算法优先选择考研高频词，干扰项选择语义相近但搭配不同的词。

P1 考试成绩雷达图

借鉴：研英真题通的能力雷达

实现：按6大题型统计正确率，生成雷达图（完形/阅读A/新题型/翻译/小作文/大作文），直观显示薄弱项。数据存在 exam:stats。

5.3 写作工坊：从"素材堆积"到"写作输出"

P0 大作文框架模板系统

借鉴：考研大作文三段式（图画描述→寓意揭示→观点论证）+ 扇贝考研的逻辑结构评分

实现：写作工坊增加"大作文"Tab，提供三段式框架：

段落功能可调用素材常用句式
第一段图画描述—As is vividly depicted in the picture...
第二段寓意揭示 + 论证写作素材（起因/经过/逻辑）、建议文论点The picture implicitly reflects...
第三段观点 + 建议同义词替换表、高级表达From my perspective...

用户在框架中填写内容时，右侧显示可拖拽插入的素材卡片（从10篇文章积累的）。

P0 小作文应用文模板库

借鉴：考研小作文10种应用文（书信/通知/告示/备忘录等）

实现：内置10种应用文模板框架，每种包含：

  • 格式要求（称呼/正文/落款的位置）
  • 开头/结尾套话库（从10篇文章的正式表达中提取）
  • 用户填写的历史作文（自动保存+版本历史）

P1 默写模式（中译英）

借鉴：TypeWords 默写模式 + 翻译题反向训练

实现：从长难句/写作素材中选择句子，显示中文译文，用户输入英文，系统逐词比对：

  • 正确词 = 绿色，错误词 = 红色，漏词 = 黄色下划线
  • 拼写错误的词自动加入"错词本"
  • 完成后显示原文对照，标记差异

价值：这是从"被动读"到"主动写"的关键跨越，直接服务翻译和写作。

P1 素材与文章的双向溯源

借鉴：MarginNote 卡片始终绑定来源段落

实现：每条写作素材/长难句/词根都记录 sourceArticleId + sourceParaIndex + sourceText。在写作工坊查看素材时，一键"回原文"跳转到对应文章的对应段落并高亮。

P2 作文自评清单

用户写完作文后，提供考研评分维度的自评清单：

  • 内容完整性（是否覆盖提纲要点）
  • 语法准确性（时态/主谓一致/冠词）
  • 词汇多样性（是否有重复词，可用替换表检查）
  • 句式多样性（是否有复合句/倒装/强调）
  • 衔接连贯性（过渡词是否充足）

每项打分后生成总分和改进建议。

5.4 跨文章数据打通：10篇不是孤岛

P0 全局词汇网络

借鉴：MarginNote 双向链接 + 刷刷题"多维词网"

实现：

  • 同一个词在多篇文章中出现时，自动建立跨文章关联
  • 生词详情页显示："这个词在文章A（第3段）、文章C（第5段）中出现过"
  • 点击可跳转对应文章对应位置
  • 词根卡片自动关联包含该词根的所有已学生词

数据结构：vocab:index 全局索引，{ word: [{articleId, paraIndex, context}] }

P1 跨文章写作素材库

写作工坊的"全部"Tab 已经混合展示所有来源，但需要增强：

  • 按主题分类（如"AI"、"经济"、"社会"），10篇文章的素材自动聚类
  • 写大作文时，按主题筛选可用论据
  • 素材卡片显示来源文章标签，可点击溯源

P1 10篇文章学习进度总览

新增"学习中心"页面（或Hub页面增强），显示：

文章阅读进度生词数长难句写作素材考试正确率错题数

AI监管阅读中153460%5

全局进度条 + 今日复习提醒（生词+错题+长难句）。

5.5 技术架构改进

P1 笔记历史改用 Delta 增量存储

借鉴：Grammarly Delta 格式（insert/delete/retain）

当前问题：每次保存存全文，10版历史 = 10份全文，浪费空间。

改进：历史版本只存与上一版的差异（Delta操作序列），恢复时从最新版反向应用。节省80%+存储空间。

P1 localStorage 容量管理增强

当前已有容量预警，但需要更主动的管理：

  • 按数据类型显示占用排行（标注/概要/翻译/写作素材/考试记录）
  • 一键清理旧文章的概要/翻译缓存（这些可以从HTML重新加载）
  • 超过80%时自动提示导出备份

P2 数据导入导出

借鉴：TypeWords 的 JSON 导入导出

一键导出全部学习数据（生词/长难句/素材/笔记/考试记录/错题）为单个JSON文件，支持在其他设备导入恢复。

P2 练习类型配置化

借鉴：Duolingo SDUI 的练习数据驱动

将考试题目抽象为 JSON 配置（type/passage/questions/options/answer/explanation），新增题型只需加配置，不改渲染代码。当前已经部分实现，可以进一步统一完形/阅读/新题型/翻译的数据结构。

六、建议实施路线图

第一阶段：补全应试闭环（1-2周）

目标：让考试模式从"做题"变成"做题→归因→复习"的完整闭环，同时补全写作30分的框架支撑。

  • P0: 错题归因系统 + 错题本间隔重复
  • P0: 大作文框架模板 + 小作文应用文模板库
  • P0: 原文可视化标注（已存内容下划线）
  • P0: 全局词汇网络（跨文章关联）

第二阶段：深化精读能力（2-3周）

目标：让阅读模式真正实现"结构解码+语言攻坚"的精读方法论。

  • P0: 段落功能标签系统
  • P1: 同义词替换表
  • P1: 长难句主干标注工具
  • P1: 默写模式（中译英）
  • P1: 素材双向溯源

第三阶段：扩展题型与数据（3-4周）

目标：覆盖完形填空，完善数据分析和技术架构。

  • P1: 完形填空自动生成
  • P1: 考试成绩雷达图
  • P1: 跨文章素材主题聚类
  • P1: 笔记历史Delta增量存储
  • P2: 10篇文章学习总览 + 数据导入导出

核心洞察

  1. 10篇文章是资产，不是孤岛：当前每篇文章的数据独立存储，但考研能力是跨文章积累的。全局词汇网络、跨文章素材聚类、学习总览是把10篇变成"一套教材"的关键。
  2. 阅读积累必须服务于考试输出：阅读模式存的生词/长难句/素材，如果不能在考试模式和写作中直接调用，就是无效积累。原文标注+素材溯源+默写模式是打通"输入→输出"的桥梁。
  3. 错题比新题更有价值：考研提分的核心不是刷更多题，而是把错题彻底搞懂。错题归因+间隔重复是从"刷题机器"到"考点预判者"的关键。
  4. 写作30分是最大增量空间：当前写作工坊只有素材积累，缺少输出框架。大作文三段式模板+小作文应用文模板+默写模式，可以快速补上30分的产品支撑。
  5. 纯前端架构完全够用：MarginNote和TypeWords证明了local-first方案的可行性。FSRS、Delta、错题归因都不需要后端，关键是数据结构设计要合理。
